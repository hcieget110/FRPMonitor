# FRP 流量监控 v1.1.4

Windows 10 / 11 x64 桌面软件，使用 Windows ETW 按进程统计 TCP / UDP、IPv4 / IPv6 的发送与接收字节数。默认监控 frpc.exe 和 frps.exe，支持多个实例和进程重启。带宽使用 Mb/s（小写 b），累计流量使用 KiB / MiB / GiB（大写 B）。

本仓库包含监控软件完整源码、图标、合成数据自检、构建流程和 [FRP 直连开机启动模板](scripts/README.md)。运行包使用文件夹版并自带 .NET 运行时；源码自行编译需要 .NET 10 SDK 和 Windows。

GitHub Actions 在 main 分支更新后编译、运行自检并打包；全部通过后按项目版本号创建 Release 并上传完整文件夹版 ZIP。同版本已有资产不会覆盖。PR 仅构建与自检，不发布。工作流使用 GitHub 自动提供的临时令牌，无需在源码内填写账号密码；本机的 FRP 配置不会参与构建。

仓库不包含实际 `frpc.toml`、认证令牌、Windows 密码、本机采集历史、运行日志或任务备份。启动脚本模板需要使用者自己的本地 FRP 配置；软件不会内置云端服务器信息。

## 运行与升级

完整解压文件夹版到固定目录，双击 FRPMonitor.exe，在 Windows UAC 提示中允许管理员权限。旁边的 DLL、JSON、语言目录与运行时必须一起保留，不要只复制 EXE。发布包自带 .NET 运行时，不需要安装 Python、.NET 或抓包驱动。

升级前从旧版托盘菜单选择“退出”，再启动新版；历史与设置保存在当前用户的本地应用数据目录，保留原有统计范围时会继续读取原历史。主窗口、悬浮窗及托盘菜单均显示 v1.1.4。托盘“版本与运行位置”可以确认实际启动的程序路径。

若开机自启已开启，且新版放在不同目录，请在新版“软件设置”保持自启勾选并保存一次，将任务更新到新版路径。

## v1.1.4 的改进

- 主窗口进程区与托盘菜单新增“启动 FRP”。调用本机已有的“开启FRP”计划任务，沿用该任务的账户、配置文件与直连启动器，不重新注册任务。

## v1.1.1 的改进

Excel 概览表将已记录的秒级最高值与最低值并列显示，单位 Mb/s。每个样本只与该分钟已知的最大、最小值比较更新，计算量为 O(1)，长期保存分钟汇总即可；这个统计不额外保存每个秒级样本。既有的短期曲线继续保留原来的内存样本。

## 主界面与悬浮窗

支持最近 5 分钟、30 分钟、2 小时、近一天（滚动 24 小时）、近一周（滚动 7 天）。顶部显示实时速率与所选范围累计流量，鼠标移到主图可以查看采样点的时间和带宽，低速值最多显示 6 位小数。

主窗口的“近一天”与底部“今天 00:00 起”不同：前者是过去 24 小时，后者从本机自然日午夜开始。

悬浮窗保持 280 × 144，默认每次启动都显示；小折线固定为最近 5 分钟，每秒刷新。左侧显示最高、中间和 0 刻度，单位 Mb/s，下方为 5 分钟前 / 2.5 分钟前 / 现在。可拖动、双击打开主界面、右键切换置顶和 50% / 70% / 94% 透明度，当前项显示勾选。

软件设置可以分别控制主窗口和悬浮窗置顶，选择 1 / 3 / 5 秒速率平均，默认 3 秒。平均按实际时长加权，仅影响显示，不改变累计字节及分钟汇总。进程名默认只读，点击“编辑”后修改，再保存应用。

关闭主窗口后继续在托盘采集；托盘或悬浮窗菜单中的“退出”才会结束软件。收起窗口和隐藏悬浮窗均不停止采集。

## 连接统计范围

设置中提供三种模式：

1. 全部进程流量：使用原有回环开关，默认排除 127.0.0.1 / ::1，统计匹配进程的其余收发。
2. 仅指定连接：只统计与填写的 IP:端口匹配的连接，不受原回环开关影响。
3. 全部非回环 + 指定回环：保留外部流量，只计入列出的本机回环端口，排除其他回环业务连接。

可填写 127.0.0.1:7890、[::1]:7890 或 *:27000，多个地址用逗号分隔。规则匹配事件两端的 IP 与端口，IPv6 建议使用方括号。连接明细勾选远端地址并点击“仅监控所选连接”会切换到第二种模式；应用后将继续跟踪这些地址，进程重启不需要重新选择 PID。

规则使用实际 IP 与端口，不自动解析域名，也不判断哪个连接属于云端隧道。云端 IP 变化后需要更新规则。连接明细最多保留 2048 个近期连接；超过时淘汰最旧记录，仅影响明细，不改变已累计字节。

FRP 若连接 127.0.0.1:7890，表示它使用本机代理入口。这一条连接不能证明最终是否经过国外节点；最终出口取决于代理配置和路由规则。软件不修改 FRP、系统代理、梯子规则或网络连接。

不同进程组合和统计口径使用独立历史文件；切回原设置可以继续读取原历史。默认“全部进程流量”的历史标识与旧版本兼容。

## 历史数据与峰值

内存保留最多 2 小时的秒级样本；持久化历史保留滚动 7 天的分钟字节数、有效采集秒数和已记录秒级峰值。一天 / 一周的曲线使用分钟平均；图表降点时保留尖峰与空缺。真正采集到的零流量保留，未采集时段留空、不跨空缺连线。

“秒级峰值”是约 1 秒采样区间速率的最大值，不是每个网络包的瞬时速率。分钟平均 = 该分钟字节数 / 有效采集秒数。例如 20 Mb/s 持续 6 秒，其余 54 秒为零，分钟平均是 2 Mb/s，已记录秒级峰值为 20 Mb/s，两者均正确。旧数据缺失的峰值不会补造；覆盖秒数可帮助判断是否完整记录了某分钟的峰值。

历史每 30 秒后台保存，正常退出等待最终保存。重启后，短期图会先显示已有分钟历史，再逐渐加入新的秒级数据。首次运行无法恢复过去一周；未采集的时段不会补造数据。超过 5 秒的采样间隔保留已知字节，但速率留空。非正常关机最多可能丢失尚未保存的约 30 秒历史。

数据保存在当前用户 %LOCALAPPDATA%\FRPMonitor：settings.json、history-统计范围标识.json、events-统计范围标识.json，以及出现界面异常时的 errors.log。每个历史文件最多约 10081 个分钟桶。.bak 为上一版历史，.damaged 为受保护的损坏文件。

## Excel 与 CSV 导出

“导出 Excel 图表”生成 .xlsx，包括分钟数据和可编辑的原生折线图。图表引用数据单元格，可修改标题、系列、坐标轴、标签和尺寸；修改带宽单元格会更新曲线，不嵌入图表图片，生成文件无需安装 Excel。

导出窗口允许设置开始 / 结束日期及 HH:mm:ss 时间。手动修改日期或时间会自动改为“自定义”。导出按分钟边界选取，边缘最多包含额外一分钟。

按天拆分时，首页为概览，每个本机自然日分别有分钟平均与可选峰值的详细图；滚动 7 天可能跨 8 个自然日。取消拆分则在首页保留完整的大幅详细图。详细图按每点约 96 像素加宽，所有有效点显示横向数值标签；可横向滚动或自行缩放。峰值图可在导出窗口关闭。

分钟数据 B / C 列为分钟平均 Mb/s，D / E 为正常采样字节，F 为有效采集秒数，H / I 为秒级峰值 Mb/s，J 为峰值记录秒数；K / L 为秒级最低 Mb/s，M 为最低值记录秒数。N / O 为异常间隔已知字节，P 为异常间隔次数；这部分字节不参与平均速率和极值。没有对应记录的旧历史留空；缺失分钟保留断线，已采集的零值保留数字 0。Excel 统计表的加权平均使用有效采集秒数。

独立“CSV 数据”只导出表格数据，CSV 无法内嵌图表。原有前 12 列顺序保持兼容，末尾增加速率不确定的上传 / 下载字节和异常间隔次数。默认文件名标明近5分钟、近30分钟、近2小时、近1天、近1周或自定义日期。

导出完成后点击“打开文件所在位置”或按回车，打开资源管理器并选中刚导出的文件。“关闭”仅关闭提示。

## 开机自启

在软件设置中勾选“开机自启”并保存可开启，取消勾选保存可关闭。默认关闭，以 Windows 任务计划程序中实际状态为准。使用当前用户登录任务 FRPMonitor-用户SID 和最高可用权限，不保存密码。登录约 10 秒后启动，主界面收起到托盘，同时显示悬浮窗。

软件应保留在设置自启时的目录；升级换目录后，在新版保存一次勾选的自启设置即可更新。关闭自启只删除本软件的登录任务，不修改 FRP 的计划任务。

## 统计限制

Mb/s = 字节每秒 × 8 / 1000000；Mb/s 与 Mbps 相同。任务管理器单列网络速率通常要对照本软件上传 + 下载的合计，并匹配 PID、统计口径和持续传输时间，瞬时刷新不同步时不能逐帧比较。

ETW 长度不是物理网卡完整帧、运营商计费或 FRP 应用层有效载荷，不额外叠加 TCP 重传事件。高负载下 ETW 事件丢失可能低估流量，软件会显示警告。只读取事件元数据，不抓取网络数据正文。

## 架构与构建

使用 C# / .NET 10、WPF 主界面、WinForms 托盘、Windows ETW 和 OpenXML 原生图表。当前版本仅支持 Windows x64，Linux 需要替换进程网络采集和桌面界面后才能运行。

职责分离：Collector / TrafficAccumulator 采集与连接计数；MonitoringService 后台周期采样与恢复；History 并发快照与有序保存；RateSmoother 加权速率；ChartData / TrafficChart 绘图缓存与刻度；ExportService / ExcelExporter 导出；DiagnosticService 诊断报告。界面只读取后台快照。文件夹版省去压缩单 EXE 的解压开销，并使用 ReadyToRun；运行后的流畅度主要取决于采样与绘图实现。

构建：dotnet build -c Release
发布：dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishReadyToRun=true -p:DebugType=None -o dist
自检：dotnet bin/Release/net10.0-windows/FRPMonitor.dll --self-test qa/self-test.json
预览：同一程序加 --preview 目录，生成标明合成数据的截图与导出演示，不读写真实历史。
诊断：--probe 报告路径 秒数，需要管理员权限，使用真实 ETW。
